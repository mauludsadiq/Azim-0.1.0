# Azim Trial v0.1.0 Specification

## Purpose

Azim Trial is the first deterministic FARD package for a tiny claim model. It does not attempt free-form generation. It performs deterministic tokenization, deterministic tensor execution, deterministic semantic evaluation, and emits receipts for replay verification.

## Components

### Tokenizer

- Longest-match greedy, left to right.
- Preserves whitespace.
- Unknown characters map to `<UNK>`.
- `tokenize(text)` returns `[<BOS>] + body + [<EOS>]`.
- `detokenize(ids)` removes `<BOS>` and `<EOS>`.
- `detokenize_ids(ids)` preserves all visible special tokens.

### Tensor core

Tensor representation:

```fard
{ dims: List(Int), data: List(Float) }
```

Matrix layout is row-major.

Implemented operations:

- vector
- matrix
- add
- sub
- scale
- dot
- row
- col
- matvec
- matmul
- relu
- silu
- rms_norm
- softmax
- argmax

### Weights

Weights are generated by a fixed integer arithmetic formula. There is no randomness. The seed is a label in the config and the arithmetic salts are fixed constants.

### Model

The neural path is:

```text
text -> tokenize -> embeddings -> Q/K/V projections -> attention -> FFN -> logits -> argmax label
```

The final verdict is not taken from the untrained neural label. It is taken from the explicit semantic evaluator.

### Semantic evaluator

World state contains explicit facts for `sky`, `grass`, `fire`, and `water`.

Supported predicates:

- `has-color`
- `has-property`
- `is-a`
- `instance-of`

Verdicts:

- `accepted`
- `rejected`
- `needs-evidence`

### Receipts

Receipts include:

- tokenizer vocabulary hash,
- fixed weights hash,
- world-state hash,
- input claim,
- neural trace fields,
- semantic result,
- final verdict.

All receipts are SHA-256 over canonical JSON.
